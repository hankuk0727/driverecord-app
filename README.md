# Drive Record

> 달리다가 눈에 띈 장면을 **버튼 한 번**으로 남기고, 차가 멈추면 **다시 가기**로 그 자리를 내비에 바로 입력하는 Pleos Connect 앱

2026 현대자동차그룹 차량용 앱 개발 공모전 출품작 · 팀 **Roadnote**

---

## 1. 어떤 앱인가요

운전 중에는 "저기 가 보고 싶다", "이 풍경 좋다" 싶어도 멈춰서 기록할 수 없습니다.
Drive Record는 **주행 중에는 큰 캡처 버튼 하나만** 보여 주고, **정차하면 자동으로** 저장한 장면 목록으로 바뀝니다.

| 상황 | 앱이 보여 주는 것 |
| --- | --- |
| 주행 중 (기어 D) | 큰 **캡처** 버튼 하나. 누르면 삑 소리와 함께 그 순간의 사진·시각·주행 모드·속도·위치가 저장됩니다. |
| 정차 중 (기어 P) | 오늘 저장한 **장면 카드 목록**. 메모 쓰기, 삭제, **다시 가기**, **폰으로 보내기** |

주행 중에는 글자를 입력하거나 목록을 넘길 필요가 없도록, 운전자 주의 분산을 줄이는 쪽으로 화면을 나눴습니다.

## 2. 주요 기능

- **캡처 한 번에 저장**: 사진 + 시각 + 주행 모드 + 속도 + 위치(장소 이름·좌표)
- **주행/정차 자동 전환**: 차량 신호(CarUxRestrictions)로 화면이 자동으로 바뀝니다. 차량 신호가 없는 폰에서는 시험용 전환 버튼이 나타납니다.
- **다시 가기**: 저장한 장소를 Pleos 내비게이션(NaviHelper)에 목적지로 보내 길 안내를 시작합니다.
- **차량 정보 스티커**: 사진 위에 시각, 속도·주행 모드, 장소를 작은 알약(pill) 모양으로 입힙니다. 장면마다 켜고 끌 수 있습니다.
- **같은 장소 회상**: 200m 안에 예전에 저장한 장면이 있으면 "이곳에서 남긴 장면" 카드로 알려 줍니다.
- **사진 보정**: 차량 카메라의 렌즈 왜곡과 보닛 부분을 정리합니다(자동 학습 포함).
- **폰으로 보내기**: 동의 후 사진을 올려 QR 코드로 휴대폰에서 24시간 동안 볼 수 있게 합니다.
- **낮/밤 자동**: 시스템 낮/밤 모드를 따라가는 Pleos 공식 색·글꼴·버튼 크기를 적용했습니다.
- **가로·세로 창 대응**: 창이 넓으면 카드를 여러 열로, 좁으면 한 열로 보여 줍니다.

## 3. 시연 방법 (APK 설치 후 바로 실행됩니다)

심사용 환경에서는 **차량 카메라 영상을 받을 방법이 없어서**, 앱에 **샘플 사진 8장**이 들어 있습니다. 캡처하면 이 사진 중 하나가 "그 순간의 카메라 화면" 역할을 합니다.

1. APK를 설치하고 앱을 실행합니다. (Pleos Connect 에뮬레이터 또는 일반 안드로이드 폰)
2. 처음에는 **주행 화면**입니다. 큰 **캡처** 버튼을 여러 번 누릅니다.
3. 화면 아래 **정차로 바꾸기** 버튼을 누르면 정차 화면(장면 목록)이 됩니다. (Pleos에서는 가상 콘솔의 기어 P/D로 자동 전환되고, 이 버튼은 보이지 않습니다.)
4. 정차 화면 **맨 아래의 "시연 설정"**을 펼쳐서 **시연 모드**를 켜면 장소와 속도가 정해진 순서(경북대학교 → 수성못 → 경북대학교 → 동성로 → 수성못)로 저장됩니다. 켠 뒤 새로 캡처하세요. **시연 초기화**는 저장된 장면을 모두 지웁니다.
5. 장면 카드에서 **차량 정보 스티커** 스위치, **한 줄 메모**, **다시 가기**, **폰으로 보내기**를 눌러 볼 수 있습니다.

> 시연 모드를 켜고 Pleos 에뮬레이터에서 **다시 가기**를 누르면 현재 위치(성남)에서 대구까지 경로가 길게 나옵니다.

### Pleos 에뮬레이터에서 기어 바꾸기
1. 에뮬레이터를 켠 상태에서 `adb forward tcp:8088 tcp:8088`
2. 브라우저에서 `http://127.0.0.1:8088/` → 화면 오른쪽 가운데 **P / D** 로 기어 변경

## 4. Pleos / 차량 연동

| 기능 | 사용한 것 |
| --- | --- |
| 주행 ↔ 정차 | AAOS `CarUxRestrictionsManager` (기어 D = 주행, P = 정차) |
| 주행 모드 (일반·에코·스포츠) | Pleos Vehicle SDK `ai.pleos.playground:Vehicle:2.3.2` |
| 현재 위치 (5초마다, 화면이 보일 때만) | Pleos NaviHelper `ai.pleos.playground:NaviHelper:3.0.5` `getCurrentLocationInfo` |
| 다시 가기 | NaviHelper `requestRoute` + 내비 화면 열기 |
| 속도 | 안드로이드 표준 `CarPropertyManager` `PERF_VEHICLE_SPEED` |

### 선언한 권한과 이유

| 권한 | 이유 |
| --- | --- |
| `android.permission.INTERNET` | 폰으로 보내기(사진 업로드) |
| `pleos.car.permission.NAVI_ROUTE` | 현재 위치 읽기, 길 안내 요청 |
| `pleos.car.permission.NAVI_ROUTE_SEARCH` | 다시 가기의 경로 요청 (이 둘을 빼면 다시 가기가 내비로 넘어가지 않는 것을 에뮬레이터에서 확인해 유지) |
| `pleos.car.permission.NAVI_CUSTOM_MAP` | 다시 가기의 내비 화면 열기 (위와 같음) |
| `pleos.car.permission.CAR_DRIVE` | 주행 모드 읽기 |
| `android.car.permission.CAR_SPEED` | 속도 읽기 (실행 중 허락 창으로 받음) |

폰이나 시연 모드에서는 이 연동을 쓰지 않고 가짜 값(`FakeVehicleData`)으로 동작합니다.

## 5. 개인정보

- 장면 사진·시각·장소·속도·메모는 **기기 안에만** 저장됩니다.
- **폰으로 보내기**를 처음 누르면 안내·동의 창이 뜨고, **동의했을 때만** 사진 한 장이 Firebase 서버에 올라갑니다. 동의하지 않아도 다른 기능은 모두 쓸 수 있습니다.
- 올린 사진은 QR 주소를 아는 사람이 **24시간** 동안 볼 수 있습니다.
- 자세한 내용: **[개인정보 처리방침 · 위치정보 안내](https://hankuk0727.github.io/driverecord-view/privacy.html)**

## 7. 빌드

APK를 설치하면 바로 실행됩니다. 소스를 직접 빌드하려면 Android Studio에서 저장소를 열고 Pleos Connect 에뮬레이터 또는 폰으로 실행하세요. Firebase 설정 파일(`google-services.json`)은 저장소에 포함되어 있습니다.

## 8. 솔직하게 말씀드리는 한계

- **카메라**: 공식 문서에서 차량 카메라 영상을 받는 SDK를 찾지 못했습니다(운영 측 안내도 "신청 절차 없음"). 그래서 이 출품작은 **샘플 사진**으로 시연합니다. 차량 카메라를 쓸 수 있게 되면 `DemoCamera` 부분만 바꾸면 됩니다.
- **속도 권한**: 주행 모드·내비 권한은 신청 없이 쓸 수 있는 SDK의 권한이고, 속도 권한(`CAR_SPEED`)만 허용 범위인지 확인하지 못했습니다. 문제가 되면 속도는 가짜 값 또는 위치 기반 값으로 바꿀 수 있습니다.
- **주행 모드**: 에뮬레이터는 이 속성을 지원하지 않아 "컴포트"라는 가짜 값으로 표시됩니다. 실제 차량에서의 값은 확인하지 못했습니다.
- **실차 미검증**: Pleos 에뮬레이터에서만 확인했습니다. 실제 차량에서의 성능(CPU·메모리, 응답 속도)은 측정하지 못했습니다. 에뮬레이터가 느린 환경에서 확인해 반응 속도는 실제와 다를 수 있습니다.
- **핸들 버튼·음성**: Pleos SDK에는 핸들 버튼 입력이 없고, 음성 인식(SpeechToText) SDK는 신청 페이지에서 "준비 중"이라 쓰지 않았습니다. 그래서 화면 버튼과 시험용 키보드 `C` 키로만 확인했고, 핸들 버튼·음성 캡처는 기획서의 확장 계획으로 둡니다.
- **서버 데이터 삭제**: 무료 플랜이라 자동 삭제(TTL)를 쓰지 못합니다. 보기 기간(24시간)이 지난 데이터는 운영자가 직접 지웁니다.
- **샘플 사진**: 시연용 사진에는 다른 차량의 번호판이 보일 수 있습니다. 영상·자료에서는 가립니다.
